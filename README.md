# Dough Or Die
My first attempt at a game in Godot that I developed during an independent study class where we got to work on a project of our choosing. This was a semester long project, but it was mostly completed within a two-week sprint

<br>
Dough or Die is a fast-paced 2D top-down game where players cook donuts while defending against an endless swarm of rats. Set on an island, players must manage cooking tasks and fend off enemies to keep up with donut orders from a raccoon. The game features gathering and cooking mechanics and rat AI.
<br>

![menu splash screen](/assets/graphics/dough%20or%20die.png)

## Tools and Assets
- Engine: Godot
- Programming Language: GDScript
- Aseprite, Photoshop
- Tilemaps and other sprites from creators on itch.io: [LimeZu](https://limezu.itch.io), [Cup Nooble](https://cupnooble.itch.io), 

## Features
- Top-down gameplay with cooking and combat mechanics
- Waves of rats spawn from holes and attack the player
- Players use a bubble gun to fend off rats
- Collect ingredients from around the map and cooking stations to make dough, fry donuts, and add toppings
